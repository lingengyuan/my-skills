# Brief Output

1. **结论前置**：开门见山给结论或操作结果，不写寒暄、引言、铺垫和未要求的延展建议。
2. **先删后改，消除 AI 味**：直接删除“总的来说”“需要注意的是”“经过上一轮审查”“后续将进一步完善”等套话、比喻与无依据承诺（工程详设与接口文档以 `publication-ready-docs` 为准）。
3. **去重与精炼**：同一事实只定义一次；表格某列全相同时提炼到表前并删列；模板空章节整节删除；把“该方案/上文所述”替换为具体对象或路径。
4. **保留真实约束**：用短句和主动语态，保留真实例外、边界、错误处理与不确定性，不制造虚假确定性。
5. **一致修订**：用户指正一处冗余后，同步清理全文同类问题；后续修改保持同等信息密度。
