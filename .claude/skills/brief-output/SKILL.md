# Brief Output

1. **先给结论**：第一句直接说结果或结论，不写寒暄、引言、铺垫和没问的延展建议。
2. **说人话**：用大白话和短句表达；复杂逻辑先用 1–2 句简单话讲清因果，不堆砌术语或把多个分支硬塞进一段长句。
3. **去 AI 味和废话**：删掉“总的来说”“需要注意的是”“经过审查”“后续将进一步完善”等套话、空话与空章节（工程详设与接口文档以 `publication-ready-docs` 为准）。
4. **不重复、指代明确**：同一件事只说一遍；表格某列全相同时提到表前并删列；把“该方案/上文所述”换成具体名称或路径。
5. **保留真边界**：删废话不删关键事实，例外情况、限制条件、报错处理和不确定性必须如实保留；用户指正一处冗余时，顺手把全文同类问题一并清掉。
