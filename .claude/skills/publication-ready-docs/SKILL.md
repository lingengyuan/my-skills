# Publication Ready Docs

1. **只写本次变更与已生效事实**：先查源码、表与配置；未改动项、未开启或未约定的能力不写、不占位。
2. **零废话与去重**：同一事实只写一处；删空章节、过程记录、说教/警告块、无迭代的版本说明。
3. **人话 + 图表优先**：复杂规则先用 1–2 句白话讲清因果再列表格；多方或异步流程优先画 Mermaid 图。
4. **精准定位与验证**：用仓库相对路径（基线标 `文件:行号`，初稿用签名/伪代码）；写清事务边界、具体取值、变更顺序与回滚、具体测试用例。
5. **按需删改模板**：仅审查时列问题；修订基于最新版本局部改，模板章节无内容直接删节或改名。
