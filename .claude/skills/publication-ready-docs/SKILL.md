# Publication Ready Docs

1. **只写已生效的事实**：先查源码、表结构与配置；未开启或未约定的能力（状态码、幂等、限流等）不写、不占位。
2. **零废话与去重**：删除空章节、过程记录、防御性包装、“请勿/不要”说教、高亮警告块及无迭代记录的 `v1.0`/版本说明；表格已定义的内容正文不再复述。
3. **人话 + 图表优先**：复杂规则先用 1–2 句白话讲清因果再用表格展开；跨系统或异步流程优先画 Mermaid 时序图/流程图。
4. **精准定位**：分开写现有行为、本次改动、不改动对象；有代码基线标 `文件:行号`，编码前初稿用签名/伪代码。
5. **边界与上线**：保留事务边界、失败后果与具体取值；涉及脚本或配置变更写明执行顺序与回滚；测试用例写具体输入与预期。
6. **局部修订**：仅审查时输出问题清单；修改时基于最新版本局部更新，沿用项目模板并删空章节。
