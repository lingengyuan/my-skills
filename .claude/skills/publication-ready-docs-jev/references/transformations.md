# 转换示例

以下只演示编辑判断。职责、机制和取值须以实际来源或明确设计决策为准。

## 范围外事项：删除

原文：程序计算销售成本，不执行 BI 抽取，也不处理邮件通知。

改为：程序计算销售成本。

## 模板空章节：删除章节

原文：消息队列。此功能不使用消息队列。

处理：删除整个章节。用户明确要求保留全部模板结构时，简写为“不适用”。

## 重复定义：保留一处

原文：表格定义字段来源；后文再次重复同一来源。

处理：保留一处权威定义。后文需要引用时指向该定义。

## 真实禁止：保留

原文：不得覆盖其他程序维护的字段。

处理：保留。该句直接限制写入范围。

## 模糊承诺：不补造机制

原文：后续将进一步确保系统稳定。

处理：删除。仅在已有确定方案时，写明对应机制。
